# Política de segurança

## Versões cobertas

O ContaAI é um projeto de hackathon. Só a branch `main` recebe correções.

## Como relatar uma vulnerabilidade

**Não abra uma issue pública.** Use o relato privado do GitHub: aba **Security** do repositório → **Report a vulnerability**. O relato não fica público, e o GitHub avisa os administradores do repositório.

Inclua, se puder:
- o que dá para fazer e o impacto;
- os passos para reproduzir (rota, corpo da requisição, versão ou commit);
- se o problema está no ContaAI ou nos motores oficiais da Receita.

Problemas nos motores da calculadora (código da Receita Federal) devem ser relatados também aos repositórios oficiais. O ContaAI só os executa nas versões fixadas.

## O que esperar

- O relato é lido e respondido pelo mesmo canal.
- Se for confirmado, a correção sai num PR, e o relato é mencionado na descrição quando a pessoa quiser crédito.

## Escopo

Todos os dados do projeto são fictícios (empresas, CNPJs e notas). Se você encontrar no repositório algo que pareça um dado real ou um segredo (chave, token, senha), relate do mesmo jeito.

O que o projeto protege e como protege está em [docs/seguranca.md](docs/seguranca.md).
